## Revisión global de trazabilidad

Comprobar que no queda ningún elemento sin enlazar:

**casos de uso → objetivos → requisitos → diseño → tareas**

- [ ] Todos los casos de uso están asociados a algún objetivo.
- [ ] Todos los objetivos tienen requisitos.
- [ ] Todos los requisitos están reflejados en el diseño.
- [ ] Todo el diseño está cubierto por tareas del plan.
- [ ] Las fechas del plan encajan con el calendario del módulo.
